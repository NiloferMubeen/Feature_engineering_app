Aggregated Features

Summarize groups of rows using statistics like mean, std, count, min, and max — turning transaction-level data into customer-level intelligence.

The Concept

From Rows to Group Summaries

Aggregated features collapse multiple rows belonging to the same entity (customer, product, store) into a single row with summary statistics. This is one of the most common feature engineering techniques in Kaggle competitions!

Example: You have 1000 transaction rows per customer. Instead of feeding all 1000, you create: average_spend, max_purchase, total_orders, spending_std, days_since_first_order — one row per customer, rich with behavioral signals.

Real-World Examples

Aggregation in Action

🛒 Retail
Customer Purchase Summary
From raw purchase records, create: avg_basket_size, total_spend_6m, purchase_frequency, max_single_purchase, category_diversity_count — all aggregated per customer for churn prediction.
🏦 Credit Risk
Account Behavior Rollup
Banks roll up monthly account transactions to: avg_balance, max_overdraft_count, min_balance_last_year, payment_consistency_std — aggregated risk signals from raw ledger data.

🔑 Key Terms
groupby
GroupBy
Pandas operation that splits data into groups, applies a function, and combines results.
agg()
Aggregation Function
Statistical summary: mean, sum, std, min, max, count, median, nunique applied to groups.
Target Enc.
Target Encoding
Aggregating the target variable per group — e.g. mean conversion rate per city.
Window
Rolling Window
Aggregation over a sliding time window — e.g. 7-day average spend.

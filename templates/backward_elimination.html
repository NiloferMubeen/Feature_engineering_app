Backward Elimination

Start with ALL features and iteratively prune the least significant one — until only the most meaningful features remain.

The Concept

Pruning from Full Model

Backward Elimination starts with all features in the model and removes them one by one. At each step, the feature with the highest p-value (least statistically significant) is removed.

The process stops when all remaining features have p-values below a significance threshold (usually 0.05). Unlike forward selection, it starts with the full model — capturing all interactions from the start.

Real-World Examples

Backward Elimination in Action

🏥 Clinical Research
Treatment Outcome Study
Researchers start with 15 patient variables. Backward elimination removes non-significant ones (age, weight, etc.) until only the 4 truly predictive factors remain in the final regression model.

Python Code

statsmodels Implementation

import statsmodels.api as sm

def backward_elimination(X, y, threshold=0.05):
  features = list(X.columns)
  while True:
    model = sm.OLS(y, sm.add_constant(X[features])).fit()
    p_vals = model.pvalues[1:] # skip intercept
    max_p = p_vals.max()
    if max_p > threshold:
      worst = p_vals.idxmax()
      features.remove(worst)
    else: break
  return features
🔑 Key Terms
p-value
p-value
Probability of the coefficient being non-zero by chance. p > 0.05 → feature is not significant → eliminate.
Significance α
Significance Threshold
Typically 0.05 (5%). Features with p > α are candidates for elimination.
OLS
Ordinary Least Squares
Linear regression method that provides p-values for each feature coefficient.
vs Forward
vs Forward Selection
Forward builds up; backward prunes down. Backward is better when most features are relevant.

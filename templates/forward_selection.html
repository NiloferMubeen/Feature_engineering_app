Forward Selection

Start with zero features and greedily add the one that improves model performance the most — step by step, until adding more features stops helping.

The Concept

Building from Scratch

Forward Selection is a greedy wrapper method. At each step, it tries adding every remaining feature to the current set, evaluates model performance with each, and keeps the one that gives the best improvement.

It stops when no feature improves performance above a threshold, or when a maximum number of features is reached. The result: a lean, high-performance feature set built from the ground up.

Python Code

mlxtend Implementation

from mlxtend.feature_selection import SequentialFeatureSelector as SFS
from sklearn.linear_model import LinearRegression

sfs = SFS(LinearRegression(),
    k_features='best',
    forward=True, # ← Forward Selection
    floating=False,
    scoring='r2',
    cv=5
)
sfs.fit(X_train, y_train)
selected = list(sfs.k_feature_names_)
🔑 Key Terms
Wrapper
Wrapper Method
Uses a model to evaluate feature subsets — more accurate than filter methods but computationally expensive.
Greedy
Greedy Algorithm
Makes the locally optimal choice at each step. Fast but may not find the globally optimal feature set.
Stopping Rule
Stopping Criterion
When to stop adding features: no improvement threshold, max features limit, or CV score plateau.
SFS
Sequential Feature Selection
sklearn's implementation of both forward and backward selection methods.
⚡ Complexity Note

With k features, forward selection requires evaluating O(k²) models. For 100 features → ~5050 model fits. Use with fast models (linear, tree) or small datasets.

Recursive Feature Elimination

Use a model's feature importances to iteratively remove the weakest features — repeatedly retraining until only the most powerful features remain.

The Concept

Recursion + Model Insight

RFE uses an estimator that exposes feature importances (like a linear model's coefficients or a tree's feature_importances_). It fits the model, ranks features by importance, removes the bottom n, then repeats — recursively.

The key advantage over Backward Elimination: RFE uses the model's own understanding of importance, not just p-values. It works with any estimator (SVM, Random Forest, Gradient Boosting) — not just linear models.

Real-World Examples

RFE in Action

🧬 Genomics
Gene Expression Selection

Python Code

sklearn RFE

from sklearn.feature_selection import RFE, RFECV
from sklearn.ensemble import RandomForestClassifier

estimator = RandomForestClassifier(n_estimators=100)

# RFE: specify number of features to keep
rfe = RFE(estimator, n_features_to_select=5, step=1)
rfe.fit(X_train, y_train)
selected = X.columns[rfe.support_]

# RFECV: auto-selects best k using cross-validation
rfecv = RFECV(estimator, step=1, cv=5)
rfecv.fit(X_train, y_train)
print(f"Optimal features: {rfecv.n_features_}")
🔑 Key Terms
RFE
Recursive Feature Elimination
Fits a model, removes weakest features, repeats — until target feature count reached.
RFECV
RFE with Cross-Validation
Like RFE but automatically selects the optimal number of features using CV scoring.
step
Step Parameter
How many features to remove per round. step=1 is safest; step=5 is faster for large datasets.
coef_/importances_
Feature Importance Source
Linear models use |coef_|; tree models use feature_importances_. SVM uses |coef_| for linear kernel.

Polynomial Features

Extend linear models to capture curved, non-linear relationships by adding squared, cubed, and higher-degree terms of your features.

The Concept

Beyond the Straight Line

Linear models fit a straight line: y = w₁x. But real-world relationships are curved. By adding x², x³, etc., we give the model the ability to fit curves while keeping the math linear (in terms of the coefficients).

The key insight: polynomial features transform the input space, not the model. A linear model trained on polynomial features becomes a polynomial model.

Real-World Examples

Polynomial Features in Action

🚗 Automotive
Speed & Braking Distance
Braking distance doesn't grow linearly with speed — it grows as speed squared! A model without speed² will always underfit this critical safety relationship.
distance ∝ speed² (not speed)
💊 Pharmacology
Drug Dose Response
Drug efficacy often follows a bell curve — too little has no effect, the sweet spot is optimal, and too much is toxic. This requires at least a degree-2 polynomial.
efficacy = w₁·dose + w₂·dose²

Python Code

Using sklearn

from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression
from sklearn.pipeline import Pipeline

# Create polynomial feature pipeline
poly_pipeline = Pipeline([
  ('poly', PolynomialFeatures(degree=2, include_bias=False)),
  ('model', LinearRegression())
])

poly_pipeline.fit(X_train, y_train)
# X with 1 feature → X with: x, x², interactions
🔑 Key Terms
Degree
Polynomial Degree
The highest power of x in the polynomial. Degree 2 = quadratic, Degree 3 = cubic.
Overfitting
Overfitting
When a model learns the training data too perfectly, including noise, and fails to generalize.
R² Score
R² Score
Coefficient of determination — how much variance in y the model explains (0 to 1).
Bias-Variance
Bias-Variance Tradeoff
Higher degree = lower bias but higher variance. Sweet spot is degree 2-4 for most problems.
⚠️ Watch Out!

With n features and degree d, polynomial features create O(nᵈ) terms. Even 10 features at degree 3 → 286 features! Always use with regularization (Ridge/Lasso).

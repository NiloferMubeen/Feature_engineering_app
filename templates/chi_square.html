Chi-Square Test

Test statistical independence between categorical features and a categorical target — the standard filter method for text classification and categorical data.

The Concept

Testing Independence

The chi-square (χ²) test checks whether two categorical variables are independent. If a feature is independent of the target, it carries no useful information — drop it. If they're dependent, the feature is informative — keep it!

The test compares observed frequencies (what we see in the data) against expected frequencies (what we'd see if they were independent). A large χ² means a large deviation from independence.

χ² = Σ [(Observed - Expected)² / Expected]
p-value → small p = dependent = useful feature
Real-World Examples

Chi-Square in Action

📧 Spam Detection
Word Presence vs Spam
Does the word "FREE" appear more often in spam vs ham emails? Chi-square quantifies this dependency. Words with high χ² scores (like "lottery", "prize") are the best features for spam classifiers.
🏥 Medical Research
Treatment vs Outcome
Is blood type dependent on a disease outcome? Chi-square tests this. If p > 0.05, blood type is independent of the disease — we can safely exclude it from the prediction model.

sklearn Implementation

from sklearn.feature_selection import chi2, SelectKBest
import numpy as np

# X must be non-negative (counts or frequencies)
selector = SelectKBest(chi2, k=10)
X_new = selector.fit_transform(X, y)

# Get scores and p-values per feature
scores, pvalues = chi2(X, y)
# p < 0.05 → feature is dependent on target → keep!
🔑 Key Terms
χ² statistic
Chi-Square Statistic
Measures deviation from independence. Higher χ² = stronger dependency between variables.
p-value
p-value
Probability of observing the data if variables are independent. p < 0.05 → dependent → keep feature.
DoF
Degrees of Freedom
(rows-1) × (cols-1) in the contingency table. Needed to look up the p-value.
Contingency Table
Contingency Table
A frequency table showing the joint distribution of two categorical variables.
⚠️ Important Constraint

Chi-square only works with non-negative values. In sklearn, use it with count features (bag-of-words) or normalize continuous features to [0,1] first.
